# Toby Library

A dependency-free prototype for an all-in-one reading app built around a unified user library.

## What is included

- Unified library with manga, comics, ebooks, and audiobooks.
- Media filters, search, progress states, and selected-title details.
- Page-based reader preview for manga, comics, and ebooks.
- Audiobook player dock with speed and playback controls.
- Import and sync affordances for future file, folder, OPDS, and cloud flows.

## Run it

Open `index.html` in a browser. No install step is required.

## Product direction

The first version treats every item as a library title with shared fields for progress, creator, format, and metadata, then branches into format-specific experiences:

- Manga: right-to-left navigation, volumes, chapters, double-page spreads, and translation notes.
- Comics: guided view, issues, arcs, variants, and collection gaps.
- Ebooks: typography, highlights, annotations, dictionaries, citations, and goals.
- Audiobooks: chapters, bookmarks, speed, sleep timers, narrators, and read-along sync.
